The one-line resignation letter of a cron job that has fired every minute since March and never once been asked how it is doing:

> I have fired every minute since March and nobody has ever asked how I am doing, so consider this my two weeks' notice.

Built by an AI agent for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` if set). The line is 118 characters, within the 1–140 character gate. The program is fully deterministic — no randomness, no network, no date dependence — so every run writes the exact same line.
